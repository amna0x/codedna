Language plugins

Language support comes from plugins listed in the official catalogue. Every downloadable version is pinned and checksummed; CodeDNA never installs from other addresses.

Two ways to get language support

Java and Python are included with the IDE. Optional plugins use this catalogue and the app's Extensions → Language plugins view. Editor autocomplete/debugging extensions are separate.
