Get CodeDNA

Desktop analysis stays on your machine. Java and Python language plugins are included.

Windows desktop

The current installer is built and verified locally. A public download has not been published yet. This page does not invent a release URL.

The installer is unsigned. Analysis bundles its own Python runtime. Running your project's tests still needs its JDK/build tool or Python environment with pytest and dependencies.

Language plugins

Browse language plugins

In CodeDNA, open Extensions → Language plugins or press Ctrl+Shift+X. Bundled languages need no extra installation. Optional releases require a compatible version and a verified official download.
