Know what your change touches, and which tests to run.

CodeDNA reads a Java change, follows the code that depends on it, and recommends the regression tests worth running. When the project's history supports it, it also estimates the risk of skipping the rest, and it says so plainly when it does not.

Get started Plugins

What it does

Change analysis

Maps a diff, or your uncommitted edits, to the classes and methods that changed.

Impact graph

Follows dependencies from the change to affected code and tests. Every link is labelled direct or likely.

Test selection

Recommends test classes with a plain reason for each. Works with Maven (multi-module) and Gradle.

Checked risk estimates

Risk-based skipping only after an audit on the project's own earlier history; otherwise it recommends the full suite.

How it is built

A Python analysis core with language plugins (Java first), a desktop IDE built on Eclipse Theia, and this site with the plugin catalogue. The IDE talks to the core on your own machine only (127.0.0.1); nothing is uploaded.

Estimates are evidence, not guarantees. CodeDNA never claims a skipped test cannot fail.
