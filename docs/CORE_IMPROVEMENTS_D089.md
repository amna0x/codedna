# D089: diagnosed support repair and valid-history preparation

## Implemented

Moonshot supports fresh public no-argument instances and bounded int-array
results (128 elements). Inputs retain the eight-element array limit and two
argument limit. Private/argument-requiring constructors, generic objects,
callbacks, dates and void/file-writing methods remain unsupported. No access
override, object fabrication or invocation sequence is guessed. Constructor
code executes under the existing trusted-code consent and lifetime limits.

Normal array outputs have strict typed bounds, repeated fresh-JVM confirmation,
JSON reports and independent JDK-only reproduction. Supplied array expectations
produce assertArrayEquals drafts with an instance receiver where applicable.
Search retains exceptional inputs and continues its remaining budget; exceptions
are never converted to normal witnesses. If no normal witness is found and an
input raised an exception, the result remains inconclusive. Array candidates now
include repeated values; shrinking cannot erase method arity.
